# 🧠 Psy Dashboard

Интерактивный дашборд на Streamlit для анализа данных психологического исследования: описательная статистика, сравнение групп, корреляции, кластерный и факторный анализ, регрессии, поиск драйверов и аномалий, сетевой и медиационный анализ.

## 📖 О проекте

Дашборд работает с данными, собранными моим [проектом-опросником](https://github.com/olmintu/psychology-research). Опросник реализует три психологические методики:

- **Братусь** — методика жизненных смыслов (8 категорий: альтруистические, экзистенциальные, гедонистические, самореализации, статусные, коммуникативные, семейные, когнитивные)
- **Мильман** — мотивационный профиль (поддержание, комфорт, статус, общение, активность, творчество, общественная польза — в сферах «жизнь» и «работа», в режимах «идеал» и «реальность»; плюс эмоциональный профиль)
- **ИПЛ** — инновационный потенциал личности (общий балл, компоненты Г/А/П, шесть типов и три стиля)

На вход подаётся Excel-файл с обработанными результатами опроса; всё остальное дашборд считает сам.

## 🚀 Возможности

Дашборд состоит из 11 страниц, каждая — отдельный аналитический модуль. Все они работают поверх единой системы фильтров (пол, возраст, образование, работа, КМНС, антифрод, плюс фильтры по производным типам и профилям).

### 📊 1. Обзор
- KPI-метрики (всего респондентов, средний возраст, преобладающий пол)
- Конструктор демографических графиков: pie / bar / treemap
- Распределения шкал: violin, boxplot
- Кросс-табуляция по любым двум признакам

### 🧩 2. Методики
- Режимы «вся группа» / «конкретный респондент»
- Профили Мильмана с зонами фрустрации (разрыв между идеалом и реальностью)
- Ранжирование смыслов по Братусю
- Структура и типы реализации ИПЛ

### 🆚 3. Сравнение
- Автоматический выбор теста: проверка нормальности → t-Welch / Mann-Whitney / ANOVA / Kruskal-Wallis
- Размеры эффекта (Cohen's d, η², rank-biserial, H-stat)
- Авто-сканер всех шкал с сортировкой по p-value
- Выгрузка полного отчёта в Excel (включая незначимые шкалы)

### 🔗 4. Корреляции
- Spearman и Pearson, тепловые карты
- FDR-коррекция (Benjamini-Hochberg) на множественные сравнения
- Фильтр связей по силе и значимости
- Режим «только межметодические связи» — убирает шум внутри одного теста

### 🔬 5. Кластерный анализ
- **Иерархическая кластеризация**: дендрограммы шкал, респондентов, clustergram
- **K-Means**: автоматический подбор оптимального k через silhouette score (от 2 до 10)
- Коэффициент силуэта для оценки качества разбиения
- Профили кластеров с автоматическим расчётом p-value
- Карта кластеров в координатах PCA
- Боксплоты ИПЛ по группам
- Выгрузка профилей и состава групп в Excel

### 📐 6. Факторный анализ
- Трёхуровневая проверка адекватности данных: соотношение n/vars, KMO, тест Бартлетта
- PCA с scree plot и критерием Кайзера
- EFA с выбором методов извлечения (Minres / ML / Principal Axis) и вращения (Varimax / Promax / Oblimin)
- Альфа Кронбаха для проверки внутренней согласованности

### 🔮 7. Поиск драйверов
- Random Forest для определения наиболее влиятельных факторов
- Сравнение Spearman и Pearson (подсветка нелинейных связей)
- Разделение на катализаторы и блокаторы
- Симулятор «что-если» для прогноза изменения целевого показателя

### 📈 8. Регрессия
Четыре подхода в одной вкладке:
- **Множественная регрессия (OLS)** — R², β-коэффициенты с p-value, доверительными интервалами и F-тестом модели
- **Иерархическая регрессия** — добавление предикторов блоками с расчётом прироста ΔR² (стандарт психологических исследований)
- **Частные корреляции** — связь между X и Y при контроле других переменных
- **Регуляризованная регрессия (Ridge / Lasso)** — для случаев мультиколлинеарности и автоматического отбора переменных

### 👽 9. Поиск аномалий
- **Isolation Forest** для поиска нетипичных профилей
- **Расстояние Махаланобиса** (с χ²-критерием на p < 0.001 / p < 0.01)
- «Рентген аномалии»: Z-оценки по всем шкалам для конкретного респондента

### 🕸️ 10. Сетевой анализ
- Граф мотивов: узлы — шкалы, рёбра — корреляции
- Ползунок порога отсечения для управления плотностью
- Фильтр межметодических связей
- Выгрузка интерактивного графа в HTML

### 🔀 11. Медиация
Проверка гипотезы «X влияет на Y через M» — пять возможных исходов:
- Полная медиация / Частичная медиация / Прямой эффект без медиации / Отсутствие эффекта / Супрессия
- Расчёт прямого (c'), косвенного (a·b) и общего (c) эффектов
- Тест значимости косвенного эффекта

## 📦 Локальный запуск

```bash
# Клонируем репозиторий
git clone https://github.com/olmintu/psy-dashboard.git
cd psy-dashboard

# Создаём виртуальное окружение
python -m venv venv
source venv/bin/activate          # Linux/Mac
# venv\Scripts\activate           # Windows

# Устанавливаем зависимости
pip install -r requirements.txt

# Запускаем
streamlit run Главная.py
```

После запуска дашборд откроется в браузере по адресу `http://localhost:8501`.

## 📥 Формат входных данных

Дашборд принимает `.xlsx`-файл, сформированный [opросником](https://github.com/olmintu/psychology-research). Ожидаемые группы колонок:

- **Демография**: `FIO`, `Gender`, `Age`, `Course`, `Work`, `Edu_Status`, `Edu_Level`, `Edu_Basis`, `University`, `Speciality`, `Family`, `Children`, `Is_KMNS`, `KMNS_Name`, `Fast_Clicker`
- **Братусь**: `B_Altruistic`, `B_Existential`, `B_Hedonistic`, `B_Self-realization`, `B_Status`, `B_Communicative`, `B_Family`, `B_Cognitive`
- **Мильман**: `M_{шкала}_{сфера}-{режим}` (например, `M_K_Zh-id` — комфорт, жизнь, идеал) + `M_Est`, `M_East`, `M_Fst`, `M_Fast`
- **ИПЛ**: `IPL_Total`, `IPL_G`, `IPL_A`, `IPL_P`, шесть типов `IPL_Type_*`, четыре уровня `IPL_Level_*`

Производные колонки (уровни Братуся, мотивационные/эмоциональные профили Мильмана, стили и структура ИПЛ) считаются автоматически, если их нет в файле — для обратной совместимости со старыми выгрузками.
